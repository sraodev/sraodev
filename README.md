# Srinivas Rao

**Principal Engineer building secure infrastructure for autonomous AI agents.**

I work at the intersection of **AI security, distributed systems, and developer infrastructure**. After 15+ years shipping systems from Linux kernel modules to cloud platforms, I am now focused on **AI Agentic Security Posture Management (AI-SPM)**.

AI agents are becoming identities with credentials, memory, tools, and the ability to act. AI-SPM is the security layer that makes those actions governable:

- authorize every tool call and sensitive action
- contain prompt injection and untrusted context
- isolate agent memory, credentials, and execution
- preserve decision provenance and audit trails
- continuously evaluate posture, policy drift, and runtime risk

> My goal: help teams deploy useful AI agents without losing control, accountability, or trust.

## What I am exploring
